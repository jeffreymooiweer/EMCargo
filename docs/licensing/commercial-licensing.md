# Commercial licensing preparation

The current LICENSE stays in place. This document does not create a commercial
offer, promise support or grant rights in third-party material.

Before offering hosted EMCargo, paid support, enterprise features or integration
services, identify the contracting party and the software revisions it can
license. Review the defined Commons Clause restriction against each service;
do not advertise a blanket support or consulting exemption.

A written agreement should identify licensed software and versions, permitted
hosting/distribution, affiliates and subcontractors, use of branding, fees,
updates and security support, service levels, liability, data processing and
termination. List third-party software, datasets and locally supplied forms
separately. A commercial EMCargo license cannot grant a publisher's rights that
the licensor does not possess.

Existing MIT copies and contributions without sufficient relicensing grants
need individual assessment. There is no automatic exclusive commercial right
over all historical EMCargo code. See `license-history.md` and `CLA-DRAFT.md`.
